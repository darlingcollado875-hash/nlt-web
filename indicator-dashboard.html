    Cómo conectarlo (una sola vez)

    1. 1. En TradingView, Pine Editor → pegá NLT Zone Engine V13.4 → Save → Add to chart. Marcá la zona con los 2 clics que te pide.
    2. 2. En la config del indicador, grupo 🌐 NLT AI (webhook), activá webhookEmit.
    3. 3. Creá una alerta (icono del reloj → Crear alerta).
    4. 4. En Condición, elegí Any alert() function call.
    5. 5. En Notificaciones → Webhook URL, pegá tu Webhook URL de arriba.
    6. 6. Guardá. En cuanto llegue el primer análisis, este panel dirá ✓ Connected y aparecerá en Analysis History.

    El token de la URL identifica tu cuenta NLT. No lo compartas. La zona se marca y se cambia siempre desde V13.4 en TradingView — este panel solo recibe y muestra el resultado.
