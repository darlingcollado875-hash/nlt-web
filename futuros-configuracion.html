Pendiente de proveedor real (Tradovate)

Estas opciones existen conceptualmente pero no se activan hasta tener confirmación oficial y credenciales de Tradovate -- no se inventan valores ni comportamientos que el proveedor real no haya confirmado.

  • Modo demo/sandbox vs producción -- pendiente de credenciales reales
  • Reconexión automática con refresh token -- pendiente de confirmar si Tradovate lo soporta
  • Límites de cuentas conectadas por API key -- pendiente de respuesta de Tradovate (ver mensaje ya enviado)
  • Gestión de riesgo por cuenta (drawdown máximo, stop diario) -- a definir cuando el copiador esté probado contra el proveedor real
